Schritt 1

Ein Punkt speichert nur x und y.

Jeder Punkt wird als kleines Objekt gespeichert. Damit kann der restliche Code statt mit unklaren Zahlenpaaren mit Punkt-Objekten arbeiten.

Merksatz: Ein Punkt ist nur eine Adresse in der Ebene.

Schritt 2

Drei Punkte verraten die Kurvenrichtung.

Die Funktion orientierung entscheidet über den mittleren Punkt q: Grün heißt behalten, Rot heißt entfernen und Gelb bedeutet gerade Linie.

D(p, q, r) = (qₓ−pₓ)(rᵧ−pᵧ) − (qᵧ−pᵧ)(rₓ−pₓ)

BEISPIEL AUS UNSERER LISTE
p = A = Punkt(-3, 0) q = B = Punkt(-2, 2) r = C = Punkt(-1, -1)
D = (1 · -1) - (2 · 2) = -5 -5 < 0 · Rechtskurve · q bleibt

Schritt 3

Zuerst werden alle Punkte sortiert.

Der Algorithmus muss wissen, was „von links nach rechts“ bedeutet. Deshalb ordnet sorted die Punktliste nach der x-Koordinate neu. Die Animation zeigt, wie jeder Punkt an seinen neuen Platz wandert.

Warum? Danach kommt jeder neue Punkt garantiert weiter rechts als der vorherige.

Schritt 4

Der nächste Punkt kommt probeweise dazu.

append hängt den nächsten Punkt hinten an die bisherige Randkette. Noch ist nicht sicher, ob alle Punkte der Kette bleiben dürfen.

Wichtig: Erst einfügen, dann die letzten drei Punkte prüfen.

Schritt 5

Eine falsche Kurve entfernt den mittleren Punkt.

Die letzten drei Punkte bilden hier keine Rechtskurve. Der mittlere Punkt liegt deshalb innerhalb der neuen Randkante und kann kein Eckpunkt der oberen Hülle sein. del kette[-2] entfernt genau ihn.

Warum while? Nach dem Entfernen müssen die neuen letzten drei Punkte erneut geprüft werden.

Schritt 6

Vorwärts entsteht die obere Hülle.

Die sortierten Punkte werden von links nach rechts verarbeitet. Am Ende enthält die Liste nur noch die Punkte am oberen Rand.

Ergebnis oben: Alle verbleibenden Teilstücke machen Rechtskurven.

Schritt 7

Rückwärts entsteht die untere Hülle.

Für die untere Hälfte wird dieselbe Funktion wiederverwendet. Der einzige Unterschied: reversed(sortiert) liefert die Punkte von rechts nach links.

Schöne Eigenschaft: Kein zweiter Algorithmus ist nötig.

Schritt 8

Beide Hälften ergeben die komplette Hülle.

Linkester und rechtester Punkt stehen in beiden Listen. Der Ausschnitt [1:-1] entfernt diese Doppelungen aus der unteren Liste. Danach werden beide Listen verbunden.

Eingabe: 8 Punkte Hülle: 7 Punkte Laufzeit: O(n log n)

"""Berechnet die konvexe Hülle einer Punktmenge.

Die konvexe Hülle ist der kleinste Rand, der alle Punkte einschließt.
Anschaulich kann man sie sich wie ein Gummiband um die äußeren Punkte vorstellen.
"""

import argparse
from dataclasses import dataclass
from pathlib import Path
from typing import Iterable


# Laut Aufgabenstellung dürfen höchstens 100 Punkte verarbeitet werden.
MAX_PUNKTE: int = 100


@dataclass(frozen=True)
class Punkt:
    """Speichert genau eine x- und eine y-Koordinate.

    Attributes:
        x: Waagerechte Position des Punktes.
        y: Senkrechte Position des Punktes.

    ``frozen=True`` verhindert, dass Koordinaten später versehentlich
    verändert werden.
    """

    x: float
    y: float


def orientierung(p: Punkt, q: Punkt, r: Punkt) -> float:
    """Bestimmt die Kurvenrichtung der drei Punkte p, q und r.

    Args:
        p: Erster Punkt der betrachteten Strecke.
        q: Mittlerer Punkt, der eventuell entfernt werden muss.
        r: Neu hinzugekommener dritter Punkt.

    Returns:
        Einen negativen Wert bei einer Rechtskurve, einen positiven Wert
        bei einer Linkskurve und 0, wenn alle drei Punkte auf einer Geraden
        liegen.
    """

    # Beide Produkte bilden zusammen die 2D-Determinante.
    # Ihr Vorzeichen verrät, auf welcher Seite q liegt.
    a: float = (q.x - p.x) * (r.y - p.y)
    b: float = (q.y - p.y) * (r.x - p.x)
    return a - b


def validiere_punkte(punkte: list[Punkt]) -> None:
    """Prüft, ob die Punktliste alle Vorgaben der Aufgabe erfüllt.

    Args:
        punkte: Die zu prüfende Liste von Punkten.

    Raises:
        ValueError: Bei mehr als 100 Punkten oder doppelten x-Koordinaten.
    """

    if len(punkte) > MAX_PUNKTE:
        raise ValueError(f"Es sind höchstens {MAX_PUNKTE} Punkte erlaubt.")

    # Ein Set enthält jeden x-Wert nur einmal. Ist es kürzer als die
    # Punktliste, muss mindestens eine x-Koordinate doppelt vorkommen.
    x_werte: set[float] = {punkt.x for punkt in punkte}
    if len(x_werte) != len(punkte):
        raise ValueError("Alle Punkte müssen unterschiedliche x-Koordinaten haben.")


def _rechte_randkette(punkte: Iterable[Punkt]) -> list[Punkt]:
    """Baut aus den Punkten eine Randkette, die nur Rechtskurven enthält.

    Args:
        punkte: Punkte in der Reihenfolge, in der sie verarbeitet werden.

    Returns:
        Die fertige Randkette ohne innen liegende Punkte.
    """

    kette: list[Punkt] = []

    for punkt in punkte:
        # Der nächste Punkt wird zunächst probeweise angehängt.
        kette.append(punkt)

        # Erst ab drei Punkten kann eine Kurvenrichtung geprüft werden.
        while len(kette) >= 3:
            p, q, r = kette[-3:]

            # Eine negative Orientierung ist die gewünschte Rechtskurve.
            # Dann darf q in der Kette bleiben.
            if orientierung(p, q, r) < 0:
                break

            # Bei einer Links- oder Geradeauskurve liegt q nicht am
            # benötigten Rand. Der vorletzte Punkt wird daher entfernt.
            del kette[-2]

    return kette


def konvexe_huelle(punkte: list[Punkt]) -> list[Punkt]:
    """Berechnet die konvexe Hülle im Uhrzeigersinn.

    Args:
        punkte: Unsortierte Eingabepunkte.

    Returns:
        Die Eckpunkte der konvexen Hülle im Uhrzeigersinn.
    """

    validiere_punkte(punkte)

    # Der Algorithmus muss die Punkte von links nach rechts durchlaufen.
    sortiert: list[Punkt] = sorted(punkte, key=lambda punkt: punkt.x)

    # Null, ein oder zwei Punkte bilden bereits selbst ihre Hülle.
    if len(sortiert) <= 2:
        return sortiert

    # Vorwärts entsteht der obere Rand.
    oben: list[Punkt] = _rechte_randkette(sortiert)

    # Rückwärts erzeugt dieselbe Funktion den unteren Rand.
    unten: list[Punkt] = _rechte_randkette(reversed(sortiert))

    # Linkester und rechtester Punkt stehen in beiden Listen.
    # [1:-1] entfernt diese beiden Doppelungen aus der unteren Liste.
    return oben + unten[1:-1]


def lies_punkte(datei: Path) -> list[Punkt]:
    """Liest Punkte aus einer Textdatei mit einer Zeile ``x y`` pro Punkt.

    Args:
        datei: Pfad zur Eingabedatei.

    Returns:
        Die eingelesenen und geprüften Punkte.

    Raises:
        OSError: Wenn die Datei nicht gelesen werden kann.
        ValueError: Wenn eine Zeile keine zwei Zahlen enthält.
    """

    punkte: list[Punkt] = []
    zeilen: list[str] = datei.read_text(encoding="utf-8").splitlines()

    for zeilennummer, rohe_zeile in enumerate(zeilen, start=1):
        # Alles hinter # ist ein Kommentar. Leere Zeilen werden ignoriert.
        zeile: str = rohe_zeile.split("#", maxsplit=1)[0].strip()
        if not zeile:
            continue

        try:
            # Leerzeichen, Komma und Semikolon sind als Trenner erlaubt.
            teile: list[str] = zeile.replace(",", " ").replace(";", " ").split()
            x_text, y_text = teile
            punkt = Punkt(float(x_text), float(y_text))
            punkte.append(punkt)
        except ValueError as fehler:
            raise ValueError(
                f"Ungültige Zeile {zeilennummer}: Erwartet werden zwei Zahlen."
            ) from fehler

    validiere_punkte(punkte)
    return punkte


def _formatiere_zahl(wert: float) -> str:
    """Gibt ganze Zahlen ohne unnötige Nachkommastelle aus."""

    return str(int(wert)) if wert.is_integer() else f"{wert:g}"


def formatiere_punkt(punkt: Punkt) -> str:
    """Formatiert einen Punkt lesbar als ``(x, y)``."""

    x_text: str = _formatiere_zahl(punkt.x)
    y_text: str = _formatiere_zahl(punkt.y)
    return f"({x_text}, {y_text})"


def main() -> None:
    """Steuert das komplette Programm: lesen, berechnen und ausgeben."""

    parser = argparse.ArgumentParser(
        description="Berechnet die konvexe Hülle einer Punktmenge."
    )
    parser.add_argument(
        "datei",
        type=Path,
        help="Textdatei mit 'x y' pro Zeile",
    )
    args: argparse.Namespace = parser.parse_args()

    try:
        punkte: list[Punkt] = lies_punkte(args.datei)
        huelle: list[Punkt] = konvexe_huelle(punkte)
    except (OSError, ValueError) as fehler:
        # parser.error zeigt die Meldung an und beendet das Programm sauber.
        parser.error(str(fehler))

    print(f"Eingabe: {len(punkte)} Punkte")
    print(f"Konvexe Hülle: {len(huelle)} Punkte (im Uhrzeigersinn)")

    for punkt in huelle:
        print(formatiere_punkt(punkt))


# main wird nur beim direkten Start dieser Datei ausgeführt.
# Beim Import, zum Beispiel in den Tests, bleibt es unangetastet.
if __name__ == "__main__":
    main()

Datenstrukturen und Elementar-Operationen.

      
Die beiden Fragen aus der Projektaufgabe, kurz beantwortet.

    


    

      
1Welche Datenstrukturen benötigen Sie?

      

        
DatenstrukturIm CodeWofür

        
          

            Punkt (Record mit zwei Zahlen)
            @dataclass(frozen=True) class Punkt
            Speichert genau eine x- und eine y-Koordinate. Unveränderlich, damit kein Punkt versehentlich verschoben wird.
          

          

            Liste / Array der Eingabepunkte
            punkte: list[Punkt], sortiert
            Hält die bis zu 100 Eingabepunkte. Nach dem Sortieren liegen sie von links nach rechts vor.
          

          

            Stack (dynamische Liste) für jede Hüllenhälfte
            kette → oben, unten
            Nimmt die Randkette auf. Neue Punkte kommen oben drauf, geprüft werden nur die obersten drei, entfernt wird nur der vorletzte. Alle drei Zugriffe kosten O(1).
          

          

            Ergebnisliste
            huelle = oben + unten[1:-1]
            Die Teilmenge von M, die die konvexe Hülle bildet, im Uhrzeigersinn.
          

          

            Menge (Hilfsstruktur zur Prüfung)
            x_werte: set[float]
            Prüft in O(n), ob alle x-Koordinaten verschieden sind.
          

        
      

    


    

      
2Welche Funktionen für Elementar-Operationen benötigen Sie?

      

        
OperationIm CodeAufwandWofür

        
          

            Orientierungstest (Determinante)
            orientierung(p, q, r)
            O(1)
            
              D = (qₓ−pₓ)(rᵧ−pᵧ) − (qᵧ−pᵧ)(rₓ−pₓ)

              D < 0 Rechtskurve, D > 0 Linkskurve, D = 0 kollinear.
              Damit lässt sich prüfen, auf welcher Seite der Geraden pr der Punkt q liegt (Tipp der Aufgabe).
            		
          

          

            Sortieren nach x
            sorted(punkte, key=lambda p: p.x)
            O(n log n)
            Legt die Reihenfolge „von links nach rechts“ fest. Rückwärts gelesen (reversed) ergibt sich „von rechts nach links“ für die untere Hülle.
          

          

            Push (Punkt anhängen)
            kette.append(punkt)
            O(1)
            Der nächste Punkt kommt probeweise ans Ende der Randkette.
          

          

            Zugriff auf die letzten drei Punkte
            p, q, r = kette[-3:]
            O(1)
            Liefert die drei Punkte für den Orientierungstest.
          

          

            Mittleren Punkt entfernen
            del kette[-2]
            O(1)
            Entfernt q bei Links- oder Geradeauskurve. Danach wird erneut getestet (while).
          

          

            Randkette aufbauen
            _rechte_randkette(punkte)
            O(n)
            Baut eine Hälfte aus Push, Test und Entfernen. Jeder Punkt wird höchstens einmal eingefügt und einmal entfernt.
          

          

            Hälften verbinden
            oben + unten[1:-1]
            O(n)
            Linkester und rechtester Punkt kommen in beiden Hälften vor und werden nur einmal übernommen.
          

          

            Eingabe prüfen
            validiere_punkte(punkte)
            O(n)
            Höchstens 100 Punkte, paarweise verschiedene x-Koordinaten.
          

          

            Einlesen / Ausgeben
            lies_punkte(), formatiere_punkt()
            O(n)
            Textdatei in Punkt-Objekte umwandeln und das Ergebnis als (x, y) ausgeben.
          

        
      

      

        Gesamt: Sortieren O(n log n) + beide Hälften O(n)
        = O(n log n) Laufzeit, O(n) zusätzlicher Speicher.
